# Gravity Supply · Catálogo

Catálogo público de Gravity Supply: https://gravitysupply.github.io

Se actualiza solo desde la app de ventas (tarea programada en Claude). No edites `catalogo.json` ni `fotos/` a mano: se reescriben en cada actualización.

- `index.html`, `estilos.css`, `catalogo.js` — la página.
- `catalogo.json` — productos, precios y tallas disponibles (sin costos ni cantidades exactas).
- `fotos/` — fotos de producto, sin datos EXIF.
